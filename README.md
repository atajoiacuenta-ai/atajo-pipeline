# atajo-pipeline
Pipeline automático de Reels para @atajos.ia.es (voz Piper, subtítulos y vídeo con ffmpeg/PIL, publicación con la API oficial de Instagram).

Secretos y variables necesarios en GitHub (Settings → Secrets and variables → Actions):
- Secreto `IG_ACCESS_TOKEN`: token de la API de Instagram. Nunca en el código.
- Variable `IG_USER_ID`: identificador numérico de la cuenta.
